# Falcon Tax Solutions

Site lives in `tax-prep/` (static GitHub Pages). Launch notes: `tax-prep/SETUP.md`.

## Team agents (`.claude/agents/`)
- `ux-ui-designer`: usability, copy clarity, accessibility, mobile layout, PDF organizer design.
- `qa-tester`: runs tests, drives pages in Chromium, hunts edge cases; run before every push that touches the estimator, tax engine, organizers, Falcon Books or Scan Reader.

## The council
When the owner says "ask the council", the board has seven lenses: marketing
strategist, productivity systems expert, realist/risk advisor, consumer law,
immigration law, UX/UI designer, and QA software tester. Each gives an
independent, non-optimistic take; then converge on one ranked decision.
